# Student-Task-Tracker

This repository contains a full-stack Task Tracker web application developed as part of a Component-Based Software Integration course assignment. It includes both frontend and backend components, showing how modular and reusable parts can be combined into a complete working system.

The React frontend is organized into multiple independent components, while the backend API and database manage task operations such as adding, updating, deleting, and tracking progress. The project demonstrates component-based architecture, integration of different system layers, and maintainable software development practices.
